# PG-13 — Вычислить ориентировочную стойкость пароля

<!-- plan-id: PG-13 -->
### User Story

Как пользователь, я хочу видеть оценку созданного пароля, чтобы понять, стоит ли изменить его параметры.

### Acceptance Criteria
