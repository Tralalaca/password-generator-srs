# Первый релиз генератора сложных паролей

Версия `v1.0.0` включает одностраничное приложение на HTML, CSS и JavaScript.

- Генерация паролей длиной от 6 до 128 символов через `crypto.getRandomValues`.
- Выбор строчных и заглавных латинских букв, цифр и специальных символов; исключение похожих символов.
- Проверка ввода, копирование пароля и ориентировочная оценка стойкости с рекомендацией.
- Локальное сохранение только настроек генерации. Сам пароль не сохраняется и не отправляется на сервер.
- Русскоязычный интерфейс с поддержкой клавиатуры и ширины экрана от 360 пикселей.

Проверка: 8 автоматических тестов и успешный CI. В Headless Chrome 158 проверены генерация, копирование, восстановление настроек и ширина 360 пикселей. Полная проверка двух последних версий Chrome, Edge и Firefox на Windows/macOS и измерение на устройстве с 2 ГБ ОЗУ остаются задачей [#38](https://github.com/Tralalaca/password-generator-srs/issues/38).
