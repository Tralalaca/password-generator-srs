# Техническое задание на разработку генератора сложных паролей

Лабораторная работа № 1 «Разработка и управление требованиями к программному обеспечению». Документ описывает требования к веб-приложению; выполнение требований проверяется по связанным Issues.

## 1. Наименование и область применения

**Наименование:** «Генератор сложных паролей» (Password Generator).

**Область применения:** создание паролей для учётных записей по заданной длине и наборам символов. Приложение работает в браузере на устройстве пользователя. Оценка стойкости носит ориентировочный характер и не гарантирует защиту от взлома.

## 2. Функциональные требования

### 2.1. Генерация пароля

1. Пользователь может установить длину от 6 до 128 символов включительно. Длина по умолчанию — 16 символов. Пустое значение, дробное число и число вне диапазона отклоняются с сообщением «Введите целое число от 6 до 128»; пароль при этом не создаётся. [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8), [Issue #11](https://github.com/Tralalaca/password-generator-srs/issues/11).
2. Пользователь может включать и выключать четыре набора символов: латинские строчные `a-z`, латинские заглавные `A-Z`, цифры `0-9` и специальные символы `!@#$%^&*()-_=+[]{};:,.?`. По умолчанию включены все четыре набора. Если не выбран ни один набор, генерация не выполняется и появляется сообщение «Выберите хотя бы один тип символов». [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8), [Issue #11](https://github.com/Tralalaca/password-generator-srs/issues/11).
3. После нажатия «Сгенерировать» отображается новый пароль заданной длины. Он содержит только разрешённые символы и не менее одного символа из каждого выбранного набора. Каждая генерация использует криптографически стойкий источник случайности браузера. [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8).
4. Пользователь может включить исключение похожих символов. При включённой опции из разрешённых наборов удаляются ровно `O`, `0`, `o`, `l`, `1`, `I`; эти символы не появляются в результате. По умолчанию опция выключена. [Issue #12](https://github.com/Tralalaca/password-generator-srs/issues/12).
5. Кнопка «Копировать» переносит показанный пароль в буфер обмена и выводит сообщение «Пароль скопирован». Если пароль ещё не создан, кнопка недоступна. Если запись в буфер обмена не удалась, выводится сообщение «Не удалось скопировать пароль»; показанный пароль остаётся доступен. [Issue #9](https://github.com/Tralalaca/password-generator-srs/issues/9).
6. После генерации показывается ориентировочная оценка по формуле `H = L × log₂(N)`, где `L` — длина пароля, а `N` — число разрешённых символов с учётом выбранных наборов и исключений. Уровни: «Слабый» при `H < 40`, «Средний» при `40 ≤ H < 60`, «Надёжный» при `H ≥ 60`. Рядом с цветом показывается название уровня; при слабом и среднем уровне выводится рекомендация увеличить длину или число наборов. [Issue #10](https://github.com/Tralalaca/password-generator-srs/issues/10).

### 2.2. Настройки генерации

1. Изменения длины, выбранных наборов и опции исключения похожих символов сохраняются автоматически после каждого изменения. При повторном открытии приложения в том же браузере настройки восстанавливаются. [Issue #11](https://github.com/Tralalaca/password-generator-srs/issues/11), [Issue #12](https://github.com/Tralalaca/password-generator-srs/issues/12), [Issue #13](https://github.com/Tralalaca/password-generator-srs/issues/13).
2. Если сохранённых настроек нет, используются значения по умолчанию, указанные в разделе 2.1. Некорректные сохранённые значения не применяются. [Issue #13](https://github.com/Tralalaca/password-generator-srs/issues/13).

## 3. Требования к надёжности

1. При неверном вводе приложение не закрывается, не заменяет уже показанный пароль и сообщает, как исправить ошибку. [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8).
2. Настройки хранятся локально в браузере. Если сохранение недоступно, приложение продолжает работать с текущими настройками и показывает сообщение «Не удалось сохранить настройки». После перезагрузки в таком случае применяются значения по умолчанию. [Issue #13](https://github.com/Tralalaca/password-generator-srs/issues/13).
3. Сгенерированные пароли не записываются в локальное хранилище и не отправляются на сервер. После закрытия страницы пароль не восстанавливается; приложение не управляет содержимым буфера обмена после копирования. [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8), [Issue #9](https://github.com/Tralalaca/password-generator-srs/issues/9).

## 4. Требования к интерфейсу

1. Подписи элементов, уровни оценки, рекомендации и сообщения об ошибках отображаются на русском языке. [Issue #14](https://github.com/Tralalaca/password-generator-srs/issues/14).
2. На одном экране доступны поле длины, четыре переключателя наборов, переключатель похожих символов, кнопка «Сгенерировать», показанный пароль, оценка и кнопка «Копировать». Для ошибки ввода сообщение размещается рядом с полем длины или блоком выбора наборов. [Issue #14](https://github.com/Tralalaca/password-generator-srs/issues/14).
3. При ширине окна 360 пикселей основные элементы не требуют горизонтальной прокрутки; все элементы управления доступны с клавиатуры и имеют видимую подпись. Оценка стойкости понятна без различения цветов. [Issue #14](https://github.com/Tralalaca/password-generator-srs/issues/14).

## 5. Требования к техническому обеспечению

1. Приложение работает как веб-страница в двух последних стабильных версиях Google Chrome, Microsoft Edge и Mozilla Firefox на Windows 10/11 и macOS. Для генерации нужен безопасный контекст браузера: HTTPS или `localhost`. [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8).
2. Для сохранения настроек должно быть разрешено локальное хранилище сайта. Пароли в нём не хранятся. [Issue #13](https://github.com/Tralalaca/password-generator-srs/issues/13).
3. На компьютере с 2 ГБ оперативной памяти после нажатия «Сгенерировать» пароль длиной до 128 символов и его оценка отображаются не позднее чем через 1 секунду. [Issue #8](https://github.com/Tralalaca/password-generator-srs/issues/8), [Issue #10](https://github.com/Tralalaca/password-generator-srs/issues/10).
