## Issue #8 — Реализовать генерацию пароля с настраиваемыми параметрами

### User Story

Как пользователь, я хочу получать новый пароль заданной длины из выбранных наборов символов, чтобы использовать его для учётной записи.

### Критерии приёмки

- [ ] При длине 6 и 128 генерация выполняется; при пустом значении, дробном числе, 5 или 129 появляется сообщение «Введите целое число от 6 до 128», новый пароль не создаётся.
- [ ] При выборе хотя бы одного набора кнопка «Сгенерировать» создаёт пароль точно заданной длины; результат содержит только символы из выбранных наборов и хотя бы по одному символу из каждого выбранного набора.
- [ ] Если все наборы выключены, генерация не выполняется и появляется сообщение «Выберите хотя бы один тип символов».
- [ ] Для каждой генерации используется криптографически стойкий источник случайности браузера; обычный `Math.random` не используется.
- [ ] Сгенерированный пароль не записывается в локальное хранилище и не передаётся на сервер. После закрытия страницы он не восстанавливается.
- [ ] На компьютере с 2 ГБ ОЗУ пароль длиной до 128 символов показывается в течение 1 секунды после нажатия.

**Связь с ТЗ:** [раздел 2.1 «Генерация пароля»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#21-генерация-пароля), [раздел 3 «Требования к надёжности»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#3-требования-к-надёжности).

## Issue #9 — Реализовать копирование пароля в буфер обмена

### User Story

Как пользователь, я хочу копировать показанный пароль одним нажатием, чтобы вставить его в поле регистрации или входа.

### Критерии приёмки

- [ ] Пока пароль не создан, кнопка «Копировать» недоступна.
- [ ] После генерации нажатие «Копировать» помещает в буфер обмена ровно показанный пароль и выводит сообщение «Пароль скопирован».
- [ ] При отказе в доступе к буферу обмена появляется сообщение «Не удалось скопировать пароль», а пароль остаётся видимым.
- [ ] Приложение не сохраняет историю скопированных паролей.

**Связь с ТЗ:** [раздел 2.1 «Генерация пароля»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#21-генерация-пароля).

## Issue #10 — Реализовать ориентировочную оценку стойкости пароля

### User Story

Как пользователь, я хочу видеть понятную оценку сгенерированного пароля, чтобы при необходимости увеличить его длину или изменить наборы символов.

### Критерии приёмки

- [ ] После генерации вычисляется `H = L × log₂(N)`, где `L` — длина пароля, `N` — число разрешённых символов после применения настроек.
- [ ] При `H < 40` показывается «Слабый», при `40 ≤ H < 60` — «Средний», при `H ≥ 60` — «Надёжный».
- [ ] Рядом с цветовым индикатором всегда есть текстовое название уровня; уровень различим без цвета.
- [ ] Для «Слабый» и «Средний» выводится рекомендация увеличить длину или число наборов.
- [ ] Оценка обновляется после каждой генерации и показывается вместе с паролем не позднее чем через 1 секунду после нажатия.

**Связь с ТЗ:** [раздел 2.1 «Генерация пароля»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#21-генерация-пароля).

## Issue #11 — Добавить настройки длины и типов символов

### User Story

Как пользователь, я хочу выбирать длину и наборы символов, чтобы получить пароль, подходящий требованиям сайта.

### Критерии приёмки

- [ ] Поле длины принимает целые числа от 6 до 128 включительно; начальное значение — 16.
- [ ] Есть четыре отдельно подписанных переключателя: латинские строчные `a-z`, латинские заглавные `A-Z`, цифры `0-9`, специальные `!@#$%^&*()-_=+[]{};:,.?`.
- [ ] При первом запуске все четыре набора включены.
- [ ] Изменение длины и набора автоматически сохраняется и восстанавливается при повторном открытии приложения в том же браузере.
- [ ] При неверной длине или отсутствии выбранных наборов показывается соответствующее сообщение из раздела 2.1 ТЗ.

**Связь с ТЗ:** [раздел 2.1 «Генерация пароля»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#21-генерация-пароля), [раздел 2.2 «Настройки генерации»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#22-настройки-генерации).

## Issue #12 — Добавить исключение похожих символов

### User Story

Как пользователь, я хочу исключать похожие символы, чтобы легче читать и переписывать пароль.

### Критерии приёмки

- [ ] Есть переключатель «Исключать похожие символы», по умолчанию выключенный.
- [ ] При включении из разрешённых наборов удаляются ровно `O`, `0`, `o`, `l`, `1`, `I`; новый пароль не содержит ни один из них.
- [ ] При выключении эти символы снова разрешены соответствующими наборами.
- [ ] Состояние переключателя сохраняется и восстанавливается при повторном открытии приложения в том же браузере.

**Связь с ТЗ:** [раздел 2.1 «Генерация пароля»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#21-генерация-пароля), [раздел 2.2 «Настройки генерации»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#22-настройки-генерации).

## Issue #13 — Реализовать автосохранение и загрузку настроек

### User Story

Как пользователь, я хочу, чтобы настройки сохранялись автоматически, чтобы не задавать их после каждого открытия приложения.

### Критерии приёмки

- [ ] Длина, выбранные наборы и опция исключения похожих символов сохраняются локально в браузере после каждого изменения.
- [ ] При повторном открытии в том же браузере сохранённые допустимые настройки восстанавливаются.
- [ ] Если настроек нет или сохранённое значение недопустимо, применяются значения по умолчанию: длина 16, все наборы включены, исключение выключено.
- [ ] Если локальное хранилище недоступно, приложение продолжает генерацию с текущими настройками и показывает сообщение «Не удалось сохранить настройки»; после перезагрузки применяются значения по умолчанию.
- [ ] Сгенерированные пароли не записываются в локальное хранилище.

**Связь с ТЗ:** [раздел 2.2 «Настройки генерации»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#22-настройки-генерации), [раздел 3 «Требования к надёжности»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#3-требования-к-надёжности).

## Issue #14 — Разработать русскоязычный интерфейс

### User Story

Как пользователь, я хочу видеть настройки, сообщения и оценку на русском языке, чтобы пользоваться генератором без перевода элементов интерфейса.

### Критерии приёмки

- [ ] На одном экране доступны поле длины, четыре переключателя наборов, переключатель похожих символов, кнопки «Сгенерировать» и «Копировать», показанный пароль и текстовая оценка.
- [ ] Все подписи, сообщения об ошибках, уровни оценки и рекомендации отображаются на русском языке.
- [ ] При ширине окна 360 пикселей основные элементы доступны без горизонтальной прокрутки.
- [ ] Все элементы управления доступны с клавиатуры и имеют видимую подпись; оценка стойкости понятна без различения цветов.
- [ ] Сообщение о неверной длине или отсутствии наборов находится рядом с соответствующим элементом управления.

**Связь с ТЗ:** [раздел 4 «Требования к интерфейсу»](https://github.com/Tralalaca/password-generator-srs/wiki/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5#4-требования-к-интерфейсу).
