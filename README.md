## Планирование разработки

План рассчитан на 28 октября — 11 декабря 2026 года. В GitHub опубликованы 24 задачи, четыре контрольные точки, публичный Project Roadmap и страница Wiki. Задачи содержат оценки трудозатрат, основные роли и зависимости. Один участник выполняет роли менеджера проекта, дизайнера, frontend-разработчика и QA-инженера. Backend-разработка не требуется: по ТЗ пароль создаётся в браузере и не передаётся на сервер.

Файл [публикации плана](scripts/publish-plan.ps1) создаёт Issues, метки ролей и сложности, Milestones, GitHub Project с датами и представлением Roadmap, а также страницу Wiki «План проекта». Для предварительной проверки без изменений в GitHub выполните `pwsh -File scripts/publish-plan.ps1 -Preview`. Для публикации нужен действующий вход `gh auth login -h github.com -s repo,project`, затем выполните `pwsh -File scripts/publish-plan.ps1`.

## Область требований

ТЗ описывает генерацию пароля длиной от 6 до 128 символов, выбор наборов символов, исключение похожих символов, копирование, ориентировочную оценку стойкости, сохранение настроек и русскоязычный интерфейс. Для генерации требуется криптографически стойкий источник случайности; пароли не сохраняются и не отправляются на сервер.

Связь требований и задач двусторонняя: каждый раздел ТЗ ссылается на соответствующую Issue, а в каждой Issue должна быть ссылка на раздел ТЗ.
